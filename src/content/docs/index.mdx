**The vanilla-JS waveform audio player — plus a bar, playlist, sound list,
analytics and a peaks CLI.** A small, zero-dependency family configured from plain markup: drop
in a script and a few `data-*` attributes and ship. About 19KB of JavaScript gzipped, no dependencies.

```html
<link rel="stylesheet" href="https://unpkg.com/@arraypress/waveform-player/dist/waveform-player.css">
<script src="https://unpkg.com/@arraypress/waveform-player/dist/waveform-player.min.js"></script>

<div data-waveform-player data-url="/audio/track.mp3" data-waveform-style="mirror"></div>
```

That is a complete, working player. Start with
[Installation](/getting-started/installation/) and
[Quick start](/getting-started/quick-start/).

<Aside type="note" title="WaveformPlayer 2.0">
	2.0 adds known durations, compact peaks, lazy loading, standard events,
	looping, volume and download controls and a `<waveform-player>` element, and
	puts each framework's components in one package. Upgrading? Read
	[Migrating from 1.x](/getting-started/migrating-from-1x/).
</Aside>

<Aside type="tip" title="Building with an AI agent?">
	Point it at [`waveformplayer.com/llms.txt`](https://waveformplayer.com/llms.txt)
	— a machine-readable reference for the whole family.
</Aside>
